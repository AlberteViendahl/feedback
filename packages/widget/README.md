# widget

The embeddable feedback widget. Not built yet.

This is where the script goes that websites (e.g. GEOtracking and SimpleSERP) include to let
their users send feedback. The feedback is stored by the backend in `convex` and handled by the
team in the admin dashboard (`apps/admin`). `apps/demo-site` is the page for testing it.

Keep widget code in this folder.
